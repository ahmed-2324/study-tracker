# Studyflow: HSC Study Tracker

A free web app that helps HSC students track their syllabus chapter by chapter, log study time, and see which chapters still need revision.

**Status:** work in progress (not publicly launched yet).

## What it does
- Chapter-by-chapter syllabus progress (not started, in progress, completed)
- Focus timer and manual study logging, with duplicate protection so one session is never counted twice
- Daily and subject-wise study goals, monthly review, and analytics
- Revision and weak-chapter tracking
- English and Bangla interface
- Several color themes
- No ads

## Syllabus coverage
- Science group: All Science, Humanities subjects and ICT, Bangla, English included
- Coming soon: Business Studies

The chapter lists have been prepared according to the HSC 2028 syllabus and may contain mistakes. If you find one, please open an issue.

## Privacy
- Guest mode: your progress is saved in your own browser only. Clearing browser data erases it.
- Google sign-in is planned but not live yet. Cloud sync is not available yet.
- No ads, and no data is sold.

## Run it locally
1. Download or clone this repository.
2. Open the folder in VS Code and run `index.html` with the Live Server extension (or open the file in a browser).

## Built with
HTML, CSS and vanilla JavaScript. Firebase Authentication is planned for Google sign-in.
